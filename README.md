# Lawbook - المنصة القانونية الاجتماعية

منصة تواصل اجتماعي متخصصة في المجال القانوني.

## المميزات

- 📝 منشورات تفاعلية مع إعجاب/تعليق/مشاركة/حفظ
- 🔍 بحث ذكي ومواضيع رائجة
- 👥 ربط مهني مع محامين وخبراء قانون
- 🎙️ مساحات صوتية مباشرة ومسجلة
- 📊 استطلاعات قانونية
- 🔔 إشعارات ذكية
- 💬 رسائل فورية
- 📱 متجاوب مع جميع الأجهزة
- 🌙 وضع مظلم احترافي

## الهيكل

```
law-social/
├── index.html          # التطبيق الرئيسي (صفحة واحدة)

```

## التشغيل

```bash
# تشغيل محلي
python3 -m http.server 8765

# ثم افتح المتصفح على
# http://localhost:8765
```
